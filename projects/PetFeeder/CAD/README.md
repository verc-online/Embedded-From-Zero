# План развития PetFeeder

## Текущий статус

Версия `v1.0` полностью работает на макетной плате.

Реализовано:

- ATmega8;
- LCD1602;
- DS3231;
- три кнопки управления;
- сервопривод SG90;
- EEPROM;
- расписание кормления;
- настройка времени;
- добавление и удаление кормлений;
- автоматическое кормление.

Следующая цель — превратить макет в законченное физическое устройство.

## Структура каталогов

    CAD/
    ├── FreeCAD/       — исходные модели
    ├── STL/           — файлы для печати
    ├── STEP/          — нейтральные 3D-модели
    ├── Images/        — рендеры и фотографии
    └── Measurements/  — размеры компонентов

    Hardware/
    ├── KiCad/         — принципиальная схема
    ├── Perfboard/     — компоновка перфоплаты
    └── BOM/           — перечень компонентов

## Принципы проектирования

Корпус должен быть:

- разборным;
- ремонтопригодным;
- удобным для прошивки;
- пригодным для повторной сборки;
- рассчитанным на замену ATmega8 и сервопривода;
- удобным для печати без лишних поддержек.

## Критерии готовности

Версия считается завершённой, когда:

- устройство работает без макетной платы;
- все компоненты закреплены;
- нет висящих проводов;
- корпус можно разобрать;
- доступен интерфейс программирования;
- питание подключается через отдельный разъём;
- кормушка проходит полный цикл;
- STL и исходники опубликованы в репозитории.
